# 决策备忘录：每网子智能体布线（PathFinder 编排层化）构想与坑

- 日期: 2026-09-27；来源: 用户主会话讨论链（席位认知 → 粗布线最简表示 → 本构想，用户原创提出）
- 性质: 构想备忘录，不改动任何现役件。落地=待主审裁量后另立 pilot 任务书；本文不预设结论。
- 相关: `MEMO-HE2024-LESSONS-2026-09-27.md`（失败可分辨/预算口径）、`route-v5-fork-ripup-r1/IMPL-RIPUP-ECON-R1-REPORT.md`（算法层先例，diff 未集成）、CANVAS 线机制四件套（M2R3 现役）、`lazy/freerouting-analysis/FREEROUTING-2.4.1-原理分析.md` §5–§7、外部检索（2026-09-27，来源清单见 §6）

## 1. 构想一页纸

> 主对话负责派发与仲裁；每个子智能体只负责**一条网**（或网组），把本网布完即停；
> 网间冲突（打架）由验证器机械检出，只把冲突方的子智能体叫回来带约束重布。

本质：把 R&R（rip-up & reroute）协商循环从 executor 引擎内部**抬升到子智能体编排层**，
引擎里的「每网重布调用」换成「LLM 子智能体会话」。三个角色分工：

| 角色 | 承担者 | 职责 |
|---|---|---|
| 派发/仲裁 | 主对话（编排体） | 分网派发、冲突归因回叫、让路裁决、预算与终止 |
| 布线 | 每网一个子智能体 | 本网粗布线（一棵带层标斯坦纳树），布完即停 |
| 眼睛 | fail-closed 验证器（现役） | 逐动作校验、拒收+原因、冲突/拥塞检测 |

## 2. 族谱（三层先例，由近及远）

1. **本库已有半个实现**。fork-ripup-r1 三机制与 PathFinder/Freerouting 同构：
   机制① 拆除成本 BASE×ESCALATION^历史次数÷绕行比、准入阈 1.5×BASE（=冲突资源逐轮涨价）；
   机制② 拆除点确定性抖动、仅 hist≥1、全局轮≥4 窗口（=破振荡）；
   机制③ 会话最优板回滚。Freerouting 原理分析 §5–§7（逐轮抬升拆除预算/成本÷绕行比/随机化 detour/振荡检测停机）即商用 R&R 同款。
   **本构想 = 把这套引擎内循环搬到编排层，A* 换 LLM 会话。** fork 的集成 diff（ripup-econ-r1.diff，17 段）截至本文仍未集成正树，机制语义可作为编排层设计的直接参照。
2. **多智能体协调层同构物：MAPF 的 Conflict-Based Search（CBS）**。各 agent 独立规划 → 冲突检测机械化 → 仅冲突方带约束重规划。启示：**仲裁者不需要懂几何，只需要会发约束**（「GND 让路，改走 i=12 走廊」），几何判断全部下沉验证器。
3. **LLM 层是空白**（2026-09-27 检索）：「LLM 多智能体 × 每网 × R&R 协商」无先人。最近邻居：Quilter（工业界 RL 全自动布线，非 LLM）、经典 R&R/Tier-Assignment 系（无 LLM）、PCBWorld（LLM-EDA 工作流，非每网代理协商）、多智能体 job routing（制造业调度，非 PCB）。**空白=机会与警告并存：没人试过，也可能没人愿意付这个 token 账单。**

## 3. 收敛配方（必须继承，否则就是玩具）

- **冲突资源逐轮涨价**：被反复争抢的走廊/格对后来者变贵（fork 机制①语义）。没有它=死抢不收敛。
- **仲裁抖动**：同分僵局确定性打破（fork 机制②语义）。没有它=两网互踢死循环。
- **让路配额/最终硬仲裁**：防某网被反复叫回永远布不通（饿死）。达到配额后仲裁者直接判谁绕（CBS 式硬约束），不再协商。
- **全局终止条件**：冲突清零 或 预算耗尽（分账口径见 §4 坑3）；每网「布完即停」只是局部态，不是终止。

## 4. 四个坑（pilot 立项前必须各有答案）

### 坑1 token 成本（第一杀手）

几百条网 × 「一次带全上下文自循环到底」派发纪律 = token 爆炸。
**解法=上下文切片**：每网 agent 只需本网端点/树形 + 邻域走廊摘要 + 拥塞图投影，复杂度 O(本网邻域) 而非 O(全板)。切片载体见 §5 表示节。网粒度 vs 网组粒度（如 L2 簇）是成本/协调的权衡轴，pilot 应显式选并记录。

### 坑2 LLM 几何心算不可靠

M2R3 实证：badgeleds V_CLEARANCE×7、crypto V_HOLE_TRACK×11——席位反复提出几何不可行动作，靠拒收+反馈换方向；本质是「提出-被拒-修正」试错，验证器当眼睛。分解到每网把问题尺度从整板降到一棵粗格斯坦纳树（真收益），但**fail-closed 校验+拒收原因反馈不可拆**；CLEARANCE-R1 正在测的走廊摘要（「沿 +j 走 i=12 列走廊最宽间隙 0.42mm」）正是本构想需要的反馈通道形态——两线结果互为输入。

### 坑3 终止、饿死与分账

- 终止：冲突清零/预算尽双条件；stop_unproductive（连续 2 轮生产性为零）纪律沿用。
- 饿死：见 §3 让路配额。
- 分账：He2024 教训④直接适用——**预算口径（每网会话数/轮数/工具上限/墙钟）prereg 冻结；终态码把「预算耗尽」「DRC 脏/未连通」「无冲突可达」分开**，不许混算一个成功率。CANVAS-PILOT 三问之③（拒收直方图/逐轮连通曲线/整轮全拒收占比）在每网粒度下更细：直方图按网展开。

### 坑4 别另起炉灶

hier 线 L2 簇分组=组粒度分解先例；CANVAS 席位=单席位整板；本构想=席位粒度推到网/网组级。
自然路径：**给画板机制四件套（换轨择优/地板/反馈通道/holes 投影）换调度器**——席位粒度整板→网/网组、冲突回叫走拒收通道、处置走 MANUAL v1.2 事件流（dispatch/nudge/stop_redispatch/accept + reason 强制，schema 现成）。定位=CANVAS-PILOT 之后的对照臂，非替代。

## 5. 燃料：粗布线最简完整表示（本构想的上下文单元）

**带层标斯坦纳树（gcell 图上，每网一棵）**：节点=粗格，边集+层标签，过孔=层变点。
编码粗布线全部四决策：连通拓扑（分支显式）/走廊（格边集，拥塞=各网边多重集直接可算）/层分配/过孔。
压缩三手段：直线段游程（`i=12, j=3..17`）、共享分母前置（格距/原点/层名表）、树用边集（公共段存一次）。
文本化示例（盲包/人读同形）：

```
GND: b@(12,4,L1)[ (12,4→12,9→18,9 L1), via(18,9)→(18,9,L2)→22,9 L2 ]
```

边界教训：**「每网一条 polyline」在多端网世界必炸**（ED-X「端点恰 2」合同崩，学费已交）——多端网必须显式树化。v5 routes 条目/VOCAB route 词形/SV2A 输出均为本表示的近似，差别在分支显式与否。

席位认知结论（2026-09-27 会话）：模型语义上知道任务（被告知一切），几何上靠验证器当眼睛（心算不可靠），元认知无直接观测通道——只能靠失败形态可测量反推。每网分解=把「失败可分辨」做到网粒度。

## 6. 若立 pilot：骨架草案（供主审裁量，非任务书）

- 人口：三板（badgeleds/bme280/crypto）归因链延续 vs 换板，待裁；板源钉冻结世界。
- 席位：每网（或网组）一个 ZCode 子智能体，全包重发、自循环到底、布完即停；harness-only。
- 调度器：主对话派发+机械冲突归因回叫+涨价/抖动继承（§3）+让路配额。
- 判据：CJ 系列同款（主判据=vs 前批可布增量、routes 归责面违例=0、DRC 对照新增=0、stop 纪律、处置事件流运营门）+ Freerouting relaxed×3 对照臂。
- 预算：prereg 冻结、终态分账（坑3）；token 只记不拦+自测代理沿用。
- 盲化边界开放问题：拥塞图投影=运行时状态非 oracle，但须防间接泄露基线/门值（leak_check 禁项适配待设计）。

## 7. 开放问题清单（立项前逐条裁）

1. 网粒度 vs 网组粒度（token 账单 × 协调复杂度）。
2. 涨价/抖动落点：调度器内（编排层）还是复用引擎机制（fork diff 集成后）。
3. 仲裁策略：纯机械（涨价+配额，推荐，无自证风险）vs 主对话语义仲裁（有干预自证效应风险，RPA 线教训同域）。
4. 冲突定义粒度：格边重叠/间距/层对——与验证器现有 V_* 拒收族的映射表。
5. 成本上限估算方法：pilot 前用三板网数×每网上下文实测做元级估算（支出门纪律）。
