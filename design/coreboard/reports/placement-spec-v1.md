## 1. 布局输入与优先级（从高到低，逐级锁定）

1. **机械锚点**：安装孔、USB-C（J5）位置、板边。
2. **主体对**：U1（MCU）→ U2（SDRAM）相对位置——先算通道再落位（§3）。
3. **功能簇**：QSPI 存储簇、各接口簇（对连接器）、晶振簇、模拟簇。
4. **电源链**：U3 buck 及其电感/二极管/输入输出电容回路。
5. **去耦电容**：归属锁定后随各自 IC 引脚落位（§2.1）。
6. **杂项**：测试点、LED/按键、丝印标注。

## 2. 就近原则（量化）

| 规则 | 目标 | 上限 |
|---|---|---|
| 2.1 去耦电容到所属电源焊盘 | ≤2.0mm | 3.0mm（每 VDD 引脚必有一颗达标） |
| 2.2 晶振到 MCU 晶振引脚 | ≤3.0mm | 4.0mm（负载电容更近，≤2.0mm） |
| 2.3 功能簇质心到目标连接器 | 簇内最远网 ≤ 40mm 走线估计 | 60mm |
| 2.4 USB 差分对端到端（MCU→J5） | ≤25mm | 35mm |
| 2.5 buck 功率回路（Cin-SW-L-Cout 外包络） | ≤15×10mm | 20×12mm |
| 2.6 总线同组器件"引脚面对引脚面"（U1 南排 vs U2、U1 东西排 vs 连接器） | 必须满足 | — |

## 3. 通道预算前置计算（落位前必做，脚本出报告）

公式：`需求通道宽 = ceil(N / 可用布线层数) × 线距(0.35mm) + 0.6mm 余量`，可用布线层数=2（F.Cu+In2，In1/B 保持完整地）。

| 通道 | 网数 N | 需求宽 | v1 实际 | v2 目标 |
|---|---|---|---|---|
| U1↔U2（FMC） | 38 | 7.3mm | 1.07mm ❌ | **≥7.5mm** |
| U1↔QSPI 簇 | 6 | 1.7mm | — | ≥2mm |
| U1↔各连接器（按簇） | 见簇表 | 按公式 | — | 逐簇列在坐标表 |
| USB 对 | 2 | 1.0mm | — | ≥1.2mm |

**硬规则**：任何两器件之间净空 < 需求通道宽的布局方案不得进入布线阶段。通道区域内禁止第三方器件/丝印侵入（坐标表附通道 keep-out 清单）。

## 4. 器件归属与跟随规则

1. 连接器 J1-J5：按**网表成员归属**分配到距其信号簇最近的板边（v1 的四边各一个可推翻；允许两边合并/对角布置）。
2. 去耦电容在原理图已按 VDD 分组（归属表由脚本从网表导出），布局时**成组随 IC 移动**，禁止散队。
3. U2 的去耦/VREF 上拉若在 v1 中远离，v2 强制划入存储区随 U2。
4. EMMC_VSEL/上拉电阻随 SDMMC2 簇。

## 5. 功能分区（分区图随坐标表发布）

```
     ┌─────────── 北边：J2（低速 GPIO/调试簇） ───────────┐
     │  [晶振区 NE·U1 引脚旁]              [QSPI 区 E]      │
     │                    ┌──────┐                          │
  西 │ [模拟角 NW]        │  U1  │← 7.5mm FMC 通道 → [U2 存储区] │ 东
  J4│                    └──────┘                          │J3
     │ [去耦·左侧引脚簇]      │                            │
     │  [电源区 SW]           南排簇                        │
     └──────────── 南边：J1 + J5(USB-C, SE) ──────────────┘
```
- 板轮廓默认维持 **70×70mm**（TBD-P1：若你的底板/外壳有对接尺寸要求请给数，连接器坐标可能因此被锁定）。
- 电源区固定 SW 角：远离晶振/模拟/USB；功率环路不跨信号区。
- 模拟角（ADC/VREF）NW：GNDA 单点接地，数字信号禁穿。

## 6. 保护区与禁区

1. 晶振 3mm 净空（含负载电容），区内无高速线规划路径。
2. SW_NODE 下方 In1 完整地，功率区正下方不布任何信号。
3. USB-C（J5）外壳区 5mm 内无晶振/时钟线。
4. 安装孔禁布区 2mm（铜与丝印）。

## 7. 焊接/DFM 规则（方便焊接）

| 项 | 规则 |
|---|---|
| 7.1 元件间距 | 0402/0603 相互 ≥0.8mm（手焊）/0.5mm（机贴，TBD-P2 定工艺后取严者）；IC 身侧 ≥1.0mm |
| 7.2 方向一致性 | 同簇同封装统一 0°/90°，极性/一脚标识方向统一朝北或朝左；去耦电容全板同向 |
| 7.3 单面贴装 | 全部贴片件 F 面（连接器可 T 面） |
| 7.4 丝印 | 位号不压焊盘；U1/U2 加一脚标记与方向说明；电源轨标注电压 |
| 7.5 测试点 | 关键网（各电源轨、NRST、BOOT0、SWD、USB DP/DM）预留 ≥0.9mm 裸铜测试点，间距 2.54 兼容 |
| 7.6 焊盘热焊盘 | 连接器 GND 盘保持花焊盘（≥2 辐条），大电流盘实连 |

## 8. 布局验收门（脚本报告，过门才进布线）

| 检查 | 方法 | 标准 |
|---|---|---|
| 通道预算 | 脚本按 §3 公式算实际净空 | 100% 达标 |
| 就近度 | 脚本报告每条 §2 指标 | 全部 ≤上限，目标值达标率 ≥80% |
| 间距 | KiCad courtyard DRC + 脚本 §7.1 | 0 违规 |
| 方向统计 | 脚本按簇统计旋转角 | 同簇同封装 100% 一致 |
| 保护区 | 脚本净空检查 §6 | 0 侵入 |
| 分区纯度 | 脚本检查功能簇质心落区 | 100% 入区 |

## 9. 布局执行方式（确定性）

- 坐标表 CSV（`ref, x, y, rot, side, zone`）为唯一事实源，评审表即评审布局；
- 脚本 `apply_layout.py` 从 CSV 写入 KiCad（幂等可回放、可 diff）；
- 任何手调必须回写 CSV（单向禁改板）。
