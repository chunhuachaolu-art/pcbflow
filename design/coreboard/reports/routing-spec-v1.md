## 1. 叠层与阻抗基线

| 层 | 用途 | 说明 |
|---|---|---|
| F.Cu | 信号：逃逸 + 关键组短距 | 元件面逃逸；USB 差分对、晶振、去耦就近 |
| In1.Cu | **完整 GND 平面** | 禁止走信号（例外见 §6.4） |
| In2.Cu | 信号：主干层 | U1↔U2 总线主通道、东西向长距 |
| B.Cu | **完整 GND 平面** | 默认无信号；允许经批准的电源短跳 |

阻抗目标（**TBD-1**：以板厂叠层定稿后重算，下表按 1.6mm 板、0.2mm 半固化片/1oz 铜预估）：
- 单端关键信号：50Ω ±15%（约 0.35~0.40mm 线宽——**本板铜长 <70mm，实际以 0.20mm 统一线宽优先，阻抗偏差可接受**，理由见 §3 注）
- USB 差分：90Ω ±15%（约 0.20/0.20mm 线宽/间距，**TBD-1 定稿**）

> 注：本板所有高速线长度 <70mm，100MHz 级信号的传输线效应以"等长+连续参考平面"为主控目标，特征阻抗精确值退居其次。若板厂叠层给出的 USB 差分几何与预估差 >30%，回头修订本节。

## 4. 对称性与拓扑条款

1. **USB 差分对**（含 _C 段）：整对同层、平行耦合走线（间距=差分间距）、换层数 ≤1 且成对、过孔数对内相等；不得穿越 SW_NODE 区与晶振 3mm 邻域。
2. **FMC 字节通道对称**：D0-7+NBL0、D8-15+NBL1 两字节组各自同层穿越 U1↔U2 通道（优先整组 In2），组间走线风格一致（同层比例、过孔数差 ≤1）。
3. **FMC 时钟**：SDCLK 拓扑点对点，禁止分支；落 U2 前最后一段直线进入。
4. **SDMMC2**：CK 先行布线并锁定；CMD/D0-3 参照 CK 长度，组内同层优先。
5. **晶体（HSE/LSE）**：负载电容对称摆位，保护区 3mm 内无高速线/SW_NODE；走线短而对称。
6. **SW_NODE**：面积最小化（宽而短），下方 In1 保持完整 GND 作回流，禁止从晶振/USB/analog 下方穿过。
7. **蛇形等长（波浪线）约束**：只允许在等长后处理阶段出现；幅度间距 ≥3 倍线宽（3W 规则）；45° 折线；整组蛇形风格一致（同振幅/间距，保持视觉对称）；优先放在接收端附近。

## 5. 层职责与通道规划（含布局前提）

1. U1↔U2 通道为主通道：**前置条件 A0 布局微调**（U1 北移 0.8 / U2 南移 1.2 → 间隙 1.07→~3.1mm），未批准前本节通道容量数字按现状 1.07mm 打五折执行。
2. In2 主干方向约定：北南向为主（U1↔U2/U1↔J1），东西向次之（U1↔J3/J4）；同向平行 ≥0.35mm 间距（0.20+2× clearance）。
3. F.Cu 只做逃逸（≤3mm）+ 关键组局部直连；长距一律下 In2。
4. In1/B：GND 平面，见 §6。

## 6. 地平面完整性

1. In1/B 不分割、不挖槽（安装孔/过孔除外）。
2. 任何关键类信号不得跨越平面开槽（本板若遵守 6.1 则自动满足）。
3. GND 缝合过孔：目标网格 ≤8mm，重点区域（J5 外壳、U3 下方、连接器排）加密至 ≤4mm。
4. In1 例外条款：允许经书面批准的 ≤2mm 短跳（须成对回流孔伴随）。
5. J5 USB-C 外壳焊盘：每盘 1 个 GND 直连孔。
6. GNDA/VDDA 模拟角：GNDA 经单点（0Ω/磁珠按原理图）接 GND；模拟区内禁止数字线穿越。

## 7. 电源分配

1. 5V（USB/排针）→ U3 TPS62085 → 3V3 主干：主干 1.0mm，负载端 0.5mm 分支；单点树状，不环回。
2. 去耦电容按 VDD 引脚就近（已有布局，A0 微调时电容随封装移动）。
3. EMMC_VSEL：0.3mm，星型从选择器件出发。
4. 大电流回流：U3 输入/输出回路面积最小（输入电容-SW-输出电容紧邻）。

## 9. KiCad 落地映射（批准后执行）

- `.kicad_pro` → net_classes 按 §2 建类（宽度/过孔尺寸/间距 0.2）；
- 自定义规则（rules）：`(rule "fmc_via_limit" (constraint ... ))` 可查部分约束；等长不可规则化，由 §8 脚本门控；
- Freerouting：DSN 导出自动携带 net class 宽度；布线顺序：关键组锁定后仅布 SIG_DEFAULT；
- 布线执行顺序：USB → FMC → SDMMC2 → QSPI → ETH → 其余 → 等长后处理 → 清理（去零长段/共线合并）→ 铺铜 → 验收。
