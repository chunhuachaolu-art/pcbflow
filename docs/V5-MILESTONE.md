# V5 里程碑定格与披露（v5.0-milestone-1）

这一页整理自 V5 里程碑的内部定格件（10-21 签署）。数字取自当时机械注入的证据清单。之后做了一轮引擎提速（0.11.0 → 0.13.0），验收标准是五板/七板逐字节等价，所以下表读数在 0.13.0 上依然成立。

## 1. 立项门原文

> 把「提案权归模型、度量权归引擎」落成一条可跑的端到端管线：模型只在排序/分配/层计划这类求解器自己不会动的自由度上给序数提案；引擎做全部几何、容量、宽度先验与成本计算，对提案逐一测量后终选。验收=真实语料 holdout 板上同时过**成功率门**（≥5 板 DRC-clean）与**失败证据门**（全部失败附合规失败证书）；证书解释失败、不折算成功率。

## 2. 门读数

| 门 | 读数 |
|---|---|
| 判据一（原口径） | **4/5**（n_sat=4，要求 5） |
| 判据二：干净板（微段豁免后） | 4/5（genuine_outstanding=0） |
| 可布域（豁免后） | **4/4 全净**（badgeleds-do-electronics / pmod-crypto / thatmicpre-v2 / thin-pod） |
| 六板全量口径 | **4/6**（bme280、tmp108 计为 FAILED） |
| 历史对照：R2 可布域 6/6 | 09-23 的旧引擎世代读数，不能当现状 |
| 测试套件（作者机器，含全部证据目录） | 3884 collected = 3880 passed + 4 xfailed，0 failed / 0 error |
| 评估器（judge）资格 | G1..G5 all_passed（qualified，但未签核） |
| 签核 | L1 里程碑 = 已签（内部定格）；**L2 生产 = false（永久门外）**；L3 judge = false |

**结论**："≥5 块 DRC-clean"差 1 块。差距是**结构性**的：这一世界下恰好只有 4 块板 SAT，可布域 4/4 全净，缺口不指向任何脏板。立项目标按"未达-结构性"口径定格。

## 4. 生产资格与里程碑永久分离

里程碑签核（L1）≠ 生产签核（L2）。L2 需要外部 SI/PI/热/EMC/DFM 分析、板厂叠层和实物上电，本项目**从未启动**这些工作。软件层面的 DRC-clean 只能称为"候选质量"，不能称为"可生产"。
